# 项目素材管理系统

一个基于 React + TypeScript + Ant Design 的项目素材管理系统。

## 技术栈

- **React 18** - UI 框架
- **TypeScript** - 类型安全
- **Ant Design 5** - UI 组件库
- **React Router 6** - 路由管理
- **Vite** - 构建工具

## 功能模块

### 核心功能
- 用户登录/认证
- 工作台概览
- 项目管理
- 文件管理
- 标签管理
- 点位管理
- 分享管理
- 回收站
- 重复文件检测
- 模型管理
- 日志查看

### 管理功能
- 部门管理
- 用户管理
- 角色管理
- 移交管理

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

## 项目结构

```
src/
├── components/     # 通用组件
├── layout/         # 布局组件
├── pages/          # 页面组件
│   └── admin/      # 管理页面
├── routes/         # 路由配置
├── store/          # 状态管理
├── styles/         # 样式文件
└── main.tsx        # 入口文件
```

## 特性

- 🎨 现代化 UI 设计
- 📱 响应式布局
